# SHIPLAB — 웹앱 배포 연습실 v6

Windows 11 데스크톱 + Microsoft Edge 스타일 화면에서 ChatGPT/Codex → GitHub → Vercel 과정을 학습하는 교육용 시뮬레이터입니다.

## 실습 탭
- **유료·자동화 버전 (기본)**: AI 프롬프트 입력 → GitHub 모의 로그인·권한 승인 → AI의 저장소 생성·커밋·푸시 → GitHub 확인 → Vercel 모의 배포.
- **무료 버전**: ChatGPT에서 HTML 코드 생성·복사 → GitHub 로그인·새 저장소 생성 → `Add file → Create new file` → `index.html` 붙여넣기 → `Commit changes` → Vercel 모의 배포.
- 각 버전별 진행 기록을 따로 보관합니다. 첫 배포 뒤 코드를 수정하면 자동 푸시 또는 수동 커밋 후 모의 재배포를 체험합니다.

## v6 개편
1. macOS 모양의 신호등 버튼 대신 **Windows 창 제어 표시, Edge 스타일 탭·주소창, Windows 11 작업 표시줄**로 구성했습니다.
2. 지나치게 길었던 상단 설명을 접고 실제 브라우저 실습 영역을 위쪽에 배치했습니다.
3. 단계별 **지금 할 일 → 왜 필요한가요? → 처음 한 번인지**를 오른쪽 안내 카드에 배치했습니다. 자세한 용어·다음 과정 설명은 펼쳐서 봅니다.
4. 주요 화면 전환에는 **약 1~1.4초**, 프롬프트 결과에는 **약 1.5초**, 푸시·배포에는 **약 2초** 대기 효과를 추가했습니다.
5. 화면 전환과 탭 이동 중 작업 충돌을 막고, 새로고침 후 AI 대기 화면이 고정되지 않게 처리했습니다.

## 안전과 실행
이 GitHub 저장소에 있는 정적 `index.html` 파일을 Vercel에서 Framework Preset Other로 배포할 수 있습니다. **배포 연습실 자체는 실제 인터넷 사이트지만, 실습 내부의 로그인·GitHub 연결·푸시·배포는 모두 가상입니다.** 실제 계정 비밀번호나 OAuth 토큰을 입력하지 않습니다.
