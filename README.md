# SHIPLAB — 바이브 코딩 배포 연습실 v7

ChatGPT/Codex → GitHub → Vercel을 **Windows 11 + Chrome 브라우저** 환경에서 처음부터 끝까지 체험하는 비공식 교육용 시뮬레이터입니다.

## 새 기능: Chrome에서 사이트별 새 탭 열기

- 처음에는 **ChatGPT 탭만** 열려 있습니다.
- AI 작업을 마치고 **GitHub에서 확인**을 누르면 화면이 자동 전환되지 않고, Chrome 탭 오른쪽의 **+ 버튼**을 눌러 새 탭을 열도록 안내합니다.
- 새 탭의 실제로 조작되는 주소창에 `github.com`을 입력하고 **Enter**를 누릅니다. 약 1.25초의 로딩 후 모의 GitHub 화면을 표시합니다.
- GitHub 작업 후에는 동일하게 **+ → `vercel.com` → Enter**로 Vercel에 접속합니다.
- 모의 배포 완료 후 **Visit**을 누르면 홈페이지 미리보기가 네 번째 탭으로 열립니다.
- 모든 탭은 이름을 눌러 이동하거나 **×**로 닫을 수 있습니다. 이전 탭에 있던 실습 내용은 유지됩니다.
- Chrome 작업 표시줄 아이콘, 탭·주소창, 새 탭 페이지(예시 Google 시작 화면)를 구성했습니다.

### 유료·자동화 버전(기본)
AI 프롬프트 → 코딩 에이전트 모의 GitHub 연결 및 권한 승인 → AI 자동 저장소 생성·커밋·푸시 → Chrome 새 탭 `github.com` 접속·파일 확인 → 또 다른 새 탭 `vercel.com` 접속 → 모의 배포.

### 무료 버전
AI 프롬프트 → HTML 코드 복사 → Chrome 새 탭 `github.com` 접속 → 모의 로그인 → 저장소 생성 → `Add file` → `index.html` 붙여넣기 → Commit changes → Chrome 새 탭 `vercel.com` 접속 → 모의 배포.

## 초보자 안내와 연출

- 노란 테두리와 말풍선으로 **클릭 위치**를 보여줍니다. 화면 옆에서 **왜 필요한지, 처음 한 번인지**를 안내합니다.
- 새 탭 화면에는 입력해야 할 URL을 크게 표시하며, 주소를 잘못 입력했을 때 연습용 안내를 보여줍니다.
- AI 응답 생성은 약 1.5초, 화면 로딩은 약 1~1.4초, 배포 진행은 약 2초의 대기 효과를 제공합니다.
- 무료/자동화 탭은 각각 실습 진행 내용을 저장합니다.

## 배포

이 저장소의 루트 `index.html`은 단일 정적 HTML 파일이며, Vercel에서 Framework Preset `Other`로 빌드 명령 없이 배포할 수 있습니다.

**주의:** 이 시뮬레이터 **자체**는 실제 Vercel에 배포된 사이트이지만, 시뮬레이터 **내부**의 사이트 주소 입력, 로그인, 권한 승인, GitHub 푸시, Vercel 배포 등은 모두 교육용 가상 동작입니다. 실제 비밀번호나 토큰을 입력하지 않습니다.
