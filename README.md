# 배포 연습실 — ChatGPT → GitHub → Vercel

이 프로젝트는 프롬프트 입력, 모의 코드 생성, GitHub 저장소 생성과 커밋, Vercel 배포를 실제 화면과 유사한 UI에서 연습하는 비공식 교육용 시뮬레이터입니다.

## 실습 방식

1. ChatGPT 화면에서 프롬프트 입력 후 코드 생성 및 복사
2. GitHub 화면에서 가상 저장소 생성, index.html 파일 붙여넣기, 커밋
3. Vercel 화면에서 가상 저장소 연결 후 배포
4. 시뮬레이터 안에서 배포된 예시 홈페이지 미리보기

**주의:** 이 저장소로 배포되는 교육용 웹사이트 자체는 실제 Vercel 주소에서 접속할 수 있지만, 사이트 내부의 GitHub·Vercel 조작은 연습용 모의실습이며 실제 계정을 생성하거나 실습자의 코드를 외부에 배포하지 않습니다.
