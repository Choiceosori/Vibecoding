# SHIPLAB — 웹앱 배포 시뮬레이터 v5

ChatGPT/Codex 스타일 AI 코딩부터 GitHub 저장소와 Vercel 배포까지 연결하는 **교육용 모의실습 웹앱**입니다.

## 두 개의 독립적인 실습 탭

### 1. 유료·자동화 버전 (기본 탭)
1. AI에게 홈페이지 제작 프롬프트 입력
2. AI 코딩 에이전트의 모의 GitHub 로그인 및 권한 승인
3. AI가 새 저장소 생성·커밋·푸시
4. GitHub에서 코드와 커밋 확인
5. Vercel 연동·Import·Deploy
6. 재수정 시 기존 GitHub 저장소로 자동 푸시 → Vercel 자동 재배포 체험

자동 푸시는 이를 지원하는 코딩 에이전트를 전제로 한 **교육용 가상 흐름**이며, 실제 기능과 요금제 지원 여부는 사용하는 서비스에 따라 달라질 수 있습니다.

### 2. 무료 버전
1. ChatGPT에서 홈페이지 코드 생성
2. HTML 코드 복사
3. GitHub 로그인·새 저장소 생성
4. `Add file → Create new file` 선택
5. 파일 이름 `index.html` 지정 및 코드 붙여넣기
6. `Commit changes`로 등록 후 파일 확인
7. Vercel 연동·Import·Deploy
8. 재수정 시 기존 GitHub 파일을 Edit·Commit → Vercel 자동 재배포 체험

**유료·자동화 탭이 최초 기본값**이며, 무료 버전은 상단 별도 탭으로 이동합니다. 탭별 실습 기록을 별도로 저장해 자유롭게 이동할 수 있습니다.

## 초보자 안내

- 모든 단계에 **왜 필요한가요? / 언제 하나요? / 다음부터는 어떻게 되나요? / 용어 설명**이 있습니다.
- 노란 클릭 표시와 짧은 행동 설명을 함께 표시합니다.
- 로그인 및 승인 팝업은 비공식 모의 화면이며 실제 비밀번호를 입력하지 않습니다.
- 무료 계정 경로에서는 실제 자동 푸시를 하지 않습니다.

## 배포

이 프로젝트의 루트 `index.html`은 정적 페이지이며, Vercel Git 연동에서 Framework Preset `Other`를 선택해 별도 빌드 없이 배포할 수 있습니다.

**시뮬레이터 자체는 실제 Vercel 사이트로 배포되지만, 내부 GitHub 로그인·저장소·푸시·배포·URL은 모두 시뮬레이션입니다.**
